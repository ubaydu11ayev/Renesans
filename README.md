# Renessans — O‘quv Markazi Boshqaruv Tizimi
**Yuridik shaxs:** “Sardoba language stars” MCHJ

---

## 💎 Loyiha haqida
Ushbu platforma zamonaviy **Neumorphism (Soft UI)** dizayn yo‘nalishida yaratilgan bo‘lib, o‘quv markazlari faoliyatini (o‘quvchilar, guruhlar, kurslar, o‘qituvchilar, dars jadvali, to‘lovlar, davomat, qarzdorlik nazorati va hisobotlar) to‘liq avtomatlashtirish uchun mo‘ljallangan tayyor tijoriy dasturiy mahsulotdir.

---

## 🚀 Ishga tushirish

### 1-usul: Oddiy ishga tushirish (Klient uchun)
Loyihadagi **`START_RENESSANS.bat`** faylini ikki marta bosing. Tizim avtomatik ravishda serverni yoqadi va brauzerda ochiladi.

### 2-usul: Terminal orqali ishga tushirish
```bash
npm run dev
# yoki
npm start
```
Brauzerda oching: **http://localhost:5173**

## 🛠 Texnologiyalar
- **Frontend:** React 19, TypeScript, Tailwind CSS (Neumorphism tokenlari bilan), Lucide Icons, Vite
- **Backend:** Node.js, Express, RESTful API
- **Ma’lumotlar bazasi:** `server/data/database.json` (avtomatik sinxronizatsiya, doimiy saqlanish va JSON Backup eksporti)
- **Dizayn uslubi:** Neumorphism (Soft UI) — Kunduzgi (#E9EDF2) va Tungi (#171E2B) rejimlar
